## EXIF: čo posiela backend (overené 5. 11.)

`exifData` je vždy plochý objekt `{ tag: string }`:

- core-dam-bundle 1.54 číta exiftool cez `-json`. `ExifTagNormalizer` prevedie skalár na text, zoznam (Keywords,
  Subject) spojí na „a, b“ a vnorené hodnoty zahodí. `ExifMetadataFilter` potom nechá len nakonfigurované tagy a
  každú hodnotu prevedie na text a skráti (`(string)`, `StringHelper::parseString`).
- Staršie verzie (do `b9d0d8ea`, 12/2025) čítali textový výstup `Tag : value`, teda tiež len texty. Ani staré dáta
  v DB nemôžu mať pole alebo objekt.

`String(value)` v `AssetMetadataExif.vue` je teda správne. Typ v common-admin
(`string | number | boolean | null`) je širší, ako treba, ale nič nekazí.
