**Verdict: changes needed.** The PR is close to the requested minimal proxy, but five Medium issues prevent it from meeting the stated contract. I found no High issue. This was a read-only review; I ran no tests.

### Medium findings

1. [The client request](/home/volar/projects/petit/core-cms/src/HttpClient/AnzuCollaborationClient.php:125) leaves redirects enabled. Symfony defaults to following up to 20, so a collaboration 302 can become a 200 from another path instead of the required 502 for an unexpected status. Set `max_redirects` to `0`.
2. [The eight-second option](/home/volar/projects/petit/core-cms/src/HttpClient/AnzuCollaborationClient.php:130) is an idle timeout, not a total request limit. A response that keeps sending data can outlast the ten-second polling interval. Add `max_duration: 8`.
3. [The raw query is appended to a URL](/home/volar/projects/petit/core-cms/src/HttpClient/AnzuCollaborationClient.php:128), which Symfony parses and normalizes: for example, `%7E` can become `~`, and a literal `#` starts a fragment. The [test decodes the outbound query](/home/volar/projects/petit/core-cms/tests/Domain/CollabStats/Controller/Adm/V1/CollabStatsControllerTest.php:91), so it does not establish byte-for-byte forwarding. The implementation needs a way to preserve the raw query, or the contract needs to permit normalization.
4. [The response header filter](/home/volar/projects/petit/core-cms/src/HttpClient/AnzuCollaborationClient.php:148) removes `Retry-After: 0`, a valid value. Filter out `null` only.
5. When collaboration reading is disabled, [the guard call](/home/volar/projects/petit/core-cms/src/HttpClient/AnzuCollaborationClient.php:121) invokes [a journal `info` log on every request](/home/volar/projects/petit/core-cms/src/Util/ExtSystemLinkGuard.php:35). The failure limiter is bypassed. A dashboard polling every ten seconds therefore produces an unbounded stream of these logs.

### Fit and scope

The six explicit actions and role checks follow the controller pattern; the session ID is constrained to 24 lowercase hex characters, so neither it nor the query can directly select a different upstream path. See [the controller](/home/volar/projects/petit/core-cms/src/Domain/CollabStats/Controller/Api/Adm/V1/CollabStatsController.php:42). The existing `anzu_collaboration` client supplies the server-side bearer token ([client config](/home/volar/projects/petit/core-cms/config/packages/clients.php:72)); the new code does not return it to the browser. Allowed statuses and bodies pass through without decoding ([client](/home/volar/projects/petit/core-cms/src/HttpClient/AnzuCollaborationClient.php:137)). The dedicated 502 handler matches the existing [Mailer handler](/home/volar/projects/petit/core-cms/src/Exception/Handler/MailerClientExceptionHandler.php:13), and ignored exceptions plus the shared limiter follow existing logging conventions ([config](/home/volar/projects/petit/core-cms/config/packages/anzu_systems_common.php:124), [limiter](/home/volar/projects/petit/core-cms/config/services/rate_limiter.php:21)).

Keep the exception and handler, limiter, focused controller test, and changelog: each serves the proxy or a project convention. The [OpenAPI declaration](/home/volar/projects/petit/core-cms/src/Domain/CollabStats/Controller/Api/Adm/V1/CollabStatsController.php:30) follows the project’s attribute style but omits the forwarded 400, 404, 429, and 503 responses. Extend those descriptions without adding DTOs. The [tests](/home/volar/projects/petit/core-cms/tests/Domain/CollabStats/Controller/Adm/V1/CollabStatsControllerTest.php:54) cover roles, common statuses, body and header forwarding, and warning damping; add cases for the findings above and the disabled path.
