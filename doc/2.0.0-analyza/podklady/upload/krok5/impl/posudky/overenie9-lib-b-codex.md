## Claim 190 — A page from the previous type can reappear

**Verdict: HOLDS. Severity: Low.** In a picker using `AAssetSelectMedia`—for example, the CMS article image and media widget—open the asset picker, click **Load more**, then click **Video** or **Podcast** while that page is loading. This is a transient display error; the following read replaces the list.

**Smallest fix: S.** Abort the outstanding list request when the type changes, before clearing the rows. This removes the brief reappearance and cancels that obsolete page request. The abort-on-next-read behavior dates to at least September 2026.

## Claim 192 — Both image embed hosts can save twice

**Verdict: PARTLY.
