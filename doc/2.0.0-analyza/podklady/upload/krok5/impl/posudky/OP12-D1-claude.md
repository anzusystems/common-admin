## The guard (question 2)

Red on the snapshot for each of the 90 and for a new unnamed control of each detected kind: yes. `STATES`: exact two-way compare, so it cannot go stale silently; it checks that a state exists and is bound, not that it is the right boolean (findings 1-2 show why that matters) and not on toggles that bind no `active` (finding 4). `DYNAMIC`: exact path+label list both ways; its key sources can miss a caller (finding 4). `aria-labelledby`: sound for targets in the same template, except overlay content (finding 4). It cannot see: what library components draw, buttons whose only content is a component, `v-bind` objects, runtime emptiness, clickable non-buttons other than `VListItem`, render functions, `tabindex="-1"`, duplicate names, and whether a state is true.
