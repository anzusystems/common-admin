3. **Info, note on 175 (`impl/OP11-D1.md:38-42`): "the names come one request later" is imprecise.** The name caches ask through a 1.5 s debounce, maxWait 5 s (`node_modules/@anzusystems/common-admin/dist/domains/cached/composables/defineCached.js:128`).
