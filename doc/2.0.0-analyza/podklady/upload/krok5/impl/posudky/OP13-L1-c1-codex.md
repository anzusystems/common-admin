**One finding:** [DamAssetImageRoiSelect.vue](/home/volar/projects/anzusystems/common-admin/src/domains/dam/cropper/components/DamAssetImageRoiSelect.vue:119) accepts another commit while a save is pending. If two commits arrive before Vue removes the cropper, the first save’s failure clears `cropperBusy`, or its read clears it while the second save still waits ([lines 112–115](/home/volar/projects/anzusystems/common-admin/src/domains/dam/cropper/components/DamAssetImageRoiSelect.vue:112)). The busy contract stated in the [changelog](/home/volar/projects/anzusystems/common-admin/doc/changelog/2.0.0.md:110) therefore does not hold for overlapping saves.

The other cycle fixes checked match the brief. Every `requestsRunning` increment has one `finally` decrement, including failed and dropped answers. Unmount clears `cropperBusy`, including during a save or the wait.
