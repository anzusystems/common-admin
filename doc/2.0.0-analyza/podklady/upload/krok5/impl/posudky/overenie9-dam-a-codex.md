**Evidence.** The [route](</home/volar/projects/petit/core-dam/vendor/anzusystems/core-dam-bundle/src/Controller/Api/Adm/V1/AssetController.php:196>) passes the request to [bulkUpdate](</home/volar/projects/petit/core-dam/vendor/anzusystems/core-dam-bundle/src/Domain/AssetMetadata/AssetMetadataBulkFacade.php:46>). Its [asset validator](</home/volar/projects/petit/core-dam/vendor/anzusystems/core-dam-bundle/src/Validator/Constraints/AssetValidator.php:21>) checks required fields, not author ownership. The [permission loop](</home/volar/projects/petit/core-dam/vendor/anzusystems/core-dam-bundle/src/Domain/AssetMetadata/AssetMetadataBulkFacade.php:101>) checks author read access; that [voter](</home/volar/projects/petit/core-dam/vendor/anzusystems/core-dam-bundle/src/Security/Voter/ExtSystemAwareVoter.php:32>) checks the user’s access to the **author’s** system, not equality with the asset’s. **Effect and fix.** Cross-system author data can be saved on an asset. Add an asset-versus-author ext-system check before the bulk update; return a validation error for a mismatch. Normal picker use would look the same. **Size: S.**
