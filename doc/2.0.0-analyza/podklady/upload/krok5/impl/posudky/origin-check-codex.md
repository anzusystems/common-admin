The configured production, stage, and development values are plain origins, so [allowedOrigin.ts](/home/volar/projects/anzusystems/krok5-praca/collab-next-wt/src/util/allowedOrigin.ts:10) compares each one exactly. Different case, scheme, port, trailing slash, whitespace, `null`, and the cited lookalike hosts fail. Empty comma-list items cannot admit an empty `Origin`, because that is rejected first. The local `^` configuration is treated as a regex over the whole header; the outer group and anchors also contain `a|b` alternatives. A browser cannot set a second `Origin` through the WebSocket API; a client that can forge headers can already claim the allowed origin.

“Reject `cross-site`, allow a missing `Sec-Fetch-Site`” is appropriate here. A missing header still has to pass the exact `Origin` check.
