## Findings

**High — A lost document lease can allow a stale build to overwrite a newer one.** The lock wrapper discards Redlock’s abort signal ([exectionLockHelper.ts](/home/volar/projects/petit/collaboration/src/util/helper/exectionLockHelper.ts:90)); the callback then reads room data and unconditionally replaces the Mongo document ([fetchDocument.ts](/home/volar/projects/petit/collaboration/src/server/document/fetchDocument.ts:60), [fetchDocument.ts](/home/volar/projects/petit/collaboration/src/server/document/fetchDocument.ts:69)). Redlock signals a failed extension but waits for the callback to finish ([Redlock source](/home/volar/projects/petit/collaboration/node_modules/@sesamecare-oss/redlock/src/index.ts:581)). If pod A loses its lease while its build or Mongo write stalls, pod B can acquire the expired lock and save changed JSON; A can then overwrite B’s document with older content. Editors reopening it see the older body. Check the signal before the write, and prevent a writer whose lease is lost from replacing a newer build.

**Medium — The purge lock can expire before the purge ends.** It has a fixed 12-second lease with no extension ([purgeRoomListener.ts](/home/volar/projects/petit/collaboration/src/server/event/listener/purgeRoomListener.ts:9), [purgeRoomListener.ts](/home/volar/projects/petit/collaboration/src/server/event/listener/purgeRoomListener.ts:28)). `fetchInfo()` calls `fetchSockets()`, and the purge calls it again before kicking users ([roomUserManager.ts](/home/volar/projects/petit/collaboration/src/manager/roomUserManager.ts:50), [purgeRoomListener.ts](/home/volar/projects/petit/collaboration/src/server/event/listener/purgeRoomListener.ts:41)). Each cluster request can take almost five seconds. If those calls plus Redis work exceed 12 seconds, a join can acquire the room lock while the purge is still kicking sockets. The joining editor may enter a room whose state was cleared or be kicked by the older purge. Extend the lease through the operation or stop the purge when ownership is lost.
