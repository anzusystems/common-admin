2.0.0 — unreleased
===

The first release with a changelog. This file only introduces the library; from here on every release gets a file of its own that lists what changed since the previous one. Releases before 2.0.0 have no reliable record.

### What it is

`@anzusystems/common-admin` is a Vue 3 and Vuetify library for administration applications built on REST APIs. It holds the components, composables and utilities that such applications need again and again, so that each of them does not have to write and maintain its own.

### What it contains

- **Lists** — filters, pagination, ordering and column settings for data tables, filters kept in the URL and in bookmarks
- **Details and forms** — layout pieces for detail pages, who created and last changed a record, form fields with validation, remote autocompletes, date and time pickers
- **Actions and navigation** — toolbar and row buttons (create, save, delete, close back to where the user came from), breadcrumbs, a guard for unsaved changes, record pages that say why their record cannot be loaded and go back
- **App shell and access** — start-up from the deployed configuration with an error page when it fails, layouts with the action bar and one place for alerts, sign-in and sign-out, token refresh, permission checks per system, a reload after a new version is deployed and a message when a page cannot be opened
- **API layer** — typed requests, fetching of lists and of records by id, commands, error handling and alerts
- **Shared screens** — list editors, users and permission groups (with a user's accounts in the other systems and a search across them), logs and jobs
- **Media and collaboration** — image widgets, asset selection, an upload queue and a region of interest editor for a digital asset management system, collaborative editing of a record
- **Foundation** — common types and helpers, messages in Slovak, English and Czech, the Vuetify configuration and themes, Sentry setup for the application and its build, eslint and oxlint configurations for the consuming applications, test helpers, a route walk that opens every page of an application against its real API in its end-to-end tests, and one `E2E_ENV` (`local`, `devel`, `staging`) choosing the environment of those tests

### Requirements

Vue 3.5, Vuetify 4, vue-router 5, Pinia 4, vue-i18n 11, VueUse 15, axios, Vuelidate, dayjs, sortablejs, `@mdi/font` and `@sentry/vue` 11, as peer dependencies; socket.io-client (for collaboration) and the lint, test and build tools the library configures are optional peers. The exact ranges are in `package.json`. Installation and setup are described in the [guide](../guide/README.md).
